# خطة تنفيذية: تجهيز وبناء تطبيق Zorvexa لنظام Android وتوفير التحميل المباشر

خطة عمل مرحلية ومركزة خطوة بخطوة تهدف إلى إعداد مشروع Zorvexa بالكامل كحزمة تطبيق Android أصلية وقابلة للتثبيت، مع توفير خيارات تحميل وتثبيت فوري ومباشر على الهواتف الذكية.

## قرارات المستخدم والخيارات المؤكدة

> [!IMPORTANT]
> **الهدف المؤكد**: تجهيز وبناء حزمة تطبيق Android (APK) وتوفير مسار تحميل وتثبيت مباشر على الهاتف.
> **أسلوب التنفيذ المعتمد**: خطة مرحلية مركزة للتنفيذ الفوري خطوة بخطوة دون تشتيت أو إبطاء.

- **القرار المؤكد 1**: اعتماد إطار عمل Capacitor الرسمي لإنشاء وتزامن مشروع Android الأصلي المتكامل.
- **القرار المؤكد 2**: توفير نظام تثبيت فوري مزدوج: تثبيت Web APK مباشر بنقرة واحدة عبر متصفح الهاتف، بالإضافة إلى هيكل بناء حزمة APK الأصلية وأتمتتها.

---

## 1. نظرة عامة والهدف الأساسي (Overview & Core Concept)

- **ماذا يقدم**: تحويل منصة Zorvexa الاجتماعية الحالية إلى تطبيق أندرويد متكامل يعمل في وضع ملء الشاشة مع أيقونة رسمية على الشاشة الرئيسية، شاشة بداية (Splash Screen)، دعم التصفح دون اتصال، والوصول المباشر للهاتف.
- **المستخدم المستهدف**: مستخدمو هواتف Android الراغبون في تشغيل Zorvexa كتطبيق مستقل من الهاتف مباشرة بدلاً من استخدام متصفح الويب التقليدي.
- **القيمة المضافة**: سرعة تشغيل فورية، وصول مباشر بضغطة زر من قائمة التطبيقات، وتجربة مستخدم شبيهة بالتطبيقات الأصلية مع حفظ البيانات والمنشورات محلياً.

---

## 2. تجربة المستخدم والتثبيت المباشر (User Experience & UX Flows)

### مسار التثبيت المباشر على الهاتف (Mobile Direct Install Flow)
1. **الفتح عبر الهاتف**: يفتح المستخدم رابط التطبيق المباشر على هاتف أندرويد.
2. **المطالبة التلقائية بالتثبيت**: تظهر بطاقة سفلية مخصصة أو زر "تثبيت Zorvexa على هاتفك" مزود بأيقونة أندرويد الرسمية.
3. **التثبيت بنقرة واحدة**: بالضغط على الزر، ينشئ نظام Android حزمة تطبيق Web APK فورية ويثبتها في درج التطبيقات دون الحاجة لمتجر Google Play أو تفعيل مصادر غير موثوقة.
4. **نافذة التحميل المباشر للملف (Direct APK Download Modal)**:
   - نافذة منبثقة أنيقة ومفصلة في شريط الأدوات/الإعدادات تمنح المستخدم:
     - رمز استجابة سريعة (QR Code) للمسح الفوري بالهاتف.
     - رابط تثبيت فوري مباشر.
     - خيار تصدير وتنزيل حزمة كود Android الكاملة الجاهزة للتجميع.

### الهوية البصرية ومظهر التطبيق على الهاتف
- **الأيقونة**: أيقونة Zorvexa التكيفية ذات الخلفية الممتدة والرمز المتوهج مع دعم Maskable Icons لتناسب أشكال أيقونات سامسونج، شاومي، وبكسل.
- **شاشة الإقلاع (Splash Screen)**: خلفية `#09090b` مع الشعار المتحرك وتدرج البنفسجي والوردي.
- **شريط الحالة والملاحة**: وضع الشفافية العصرية المتوافقة مع أشرطة ملاحة أندرويد الافتراضية.

## 3. القرارات التقنية والمراحل التنفيذية (Key Implementation Phases)

### المرحلة الأولى: تكوين مشروع Android الأصلي ومكتبات Capacitor
- تثبيت حزمة `@capacitor/android` في المشروع.
- توليد مجلد ومصادر Android الرسمية عبر أمر `npx cap add android`.
- مزامنة كود الواجهة المبني (`dist/`) وأصول الـ Assets مع مجلد أندرويد عبر `npx cap sync android`.

### المرحلة الثانية: ضبط إعدادات AndroidManifest وصلاحيات النظام
- التأكد من ضبط `appId` على `app.zorvexa.social`.
- تكوين إعدادات الـ Deep Linking، وشريط الحالة، وإذن الوصول للإنترنت والكاميرا/الصور لرفع منشورات الوسائط.
- إعداد ملف `build.gradle` ليكون متوافقاً مع أحدث إصدارات Android SDK (API 34+).

### المرحلة الثالثة: إعداد سير عمل الأتمتة لبناء حزمة APK السحابية (CI/CD Automated Build)
- إضافة ملف سير عمل GitHub Actions جاهز (`.github/workflows/build-apk.yml`) يقوم عند الرفع بما يلي:
  - إعداد بيئة Java 17 و Android SDK.
  - تنفيذ تجميع `gradlew assembleDebug`.
  - توليد وتصدير ملف `app-debug.apk` كرابط تحميل مباشر متاح للجميع.

### المرحلة الرابعة: نافذة التثبيت والتحميل المباشر التفاعلية داخل Zorvexa
- تحديث مكون `AndroidInstallModal.tsx` ليوفر:
  - زر تثبيت سريع وفوري للأندرويد.
  - رمز QR للتحميل السريع من شاشة الكمبيوتر إلى الهاتف.
  - تعليمات واضحة للمستخدمين خطوة بخطوة.

## الخطوات القادمة فور اعتماد الخطة

1. تثبيت حزمة `@capacitor/android` وإجراء عملية Build كاملة.
2. إنشاء مجلد مشروع `android` المتكامل ومزامنته بجميع الأصول.
3. إنشاء سير عمل بناء ملف الـ APK التلقائي (`build-apk.yml`).
4. تفعيل نافذة التثبيت والتحميل المباشر وتجربتها للتأكد من سلاسة العمل.
